## 해석 범위

- 기존 테스트 통과를 모든 인증 경계·동시성·운영 환경 검증으로 해석하지 않습니다.
- 일부 검색 컨트롤러 테스트는 직접 구성한 MockMvc를 사용하므로, 테스트 통과만으로 보안 필터 적용을 증명하지 않습니다.
- 실제 원격 PostgreSQL에는 접속하지 않았습니다.
- AI 모델의 예측 성능이나 투자 성과는 이 저장소 검증 대상이 아닙니다.
