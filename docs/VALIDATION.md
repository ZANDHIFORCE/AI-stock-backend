## 2026-10-19: 로컬 JWT 키 재검증

아래 구조 정리 이후, 로컬 설정의 고정 JWT 키를 제거했습니다. `JWT_SECRET`이 없거나 비어 있으면 로컬 설정에서만 `SecureRandom`으로 32바이트 임시 키를 생성합니다. 기본 실행은 외부 `JWT_SECRET`이 필요합니다. 서명 알고리즘(HS256), 만료 시간, 필터와 접근 경로는 바꾸지 않았습니다.

- 같은 JDK 17·Gradle 8.13 환경에서 `.\gradlew.bat clean test bootJar --offline --no-daemon --max-workers=2` 성공. **기존 13개와 추가 3개, 총 16개 테스트 통과**, 실패·오류·건너뛰기 0개.
- 추가 테스트에서 같은 인증 컴포넌트의 토큰 재검증, 새 컨텍스트에서 이전 토큰 거부, 외부 키를 지정한 두 컨텍스트의 토큰 호환, 기본 설정에서 키 누락 시 시작 실패를 확인했습니다. 테스트용 외부 키도 실행 중 난수로 생성했습니다.
- `JWT_SECRET`과 DB 환경변수를 제거한 실행 JAR를 `127.0.0.1:18092`의 로컬 H2로 확인했습니다. 홈·로그인·가입 화면 200, 익명 검색 API 302, CSRF를 포함한 가입·로그인·주식 등록 302, 주식 등록 화면 200을 확인했습니다. API 로그인 200 이후 세션 쿠키 없이 같은 JWT로 검색을 두 번 요청하여 모두 200과 Gap 20을 확인하고 서버를 종료했습니다.

로컬 루프백 통신을 차단한 샌드박스 밖에서 빌드와 HTTP 검증을 완료했습니다. 의존성은 기존 캐시만 사용했고 원격 DB에 접속하지 않았습니다. 아래 검증 기록은 변경 전 이력으로 유지합니다.

## 2026-10-19: 구조와 로컬 실행 정리

기준 코드: `91b1e480c378cd32a194e1e3007ead81c14454fc`에 이번 변경 적용.
환경: Windows, Oracle JDK 17.0.0.1, Gradle Wrapper 8.13, 로컬 H2.

- 변경 전: 외부 H2 설정과 선택적 데이터 경로로 **기존 13개 테스트 통과**, 실패·오류·건너뛰기 0개.
- 변경 후: `.\gradlew.bat clean test bootJar --offline --no-daemon --max-workers=2` 성공. **동일 13개 테스트 통과**, 실패·오류·건너뛰기 0개. DB 환경변수 없이 테스트 리소스의 H2 설정을 사용했습니다.
- 기본 패키지를 `nemsi.aistock`, 저장소 폴더를 `repository`, 주식 템플릿을 `create_stock_form.html`·`stock_list.html`로 정리했습니다.
- 누락된 Wrapper JAR와 맞는 실행 스크립트를 복구하고 Gradle 8.13·공식 배포 체크섬을 지정했습니다.
- 주석뿐인 `data.sql`을 제거했습니다. 로컬은 빈 H2로 시작하며, 기본 PostgreSQL 접속값과 JWT 비밀키는 외부 설정에서 받습니다.
- `local` 프로필의 실행 JAR를 `127.0.0.1:18091`에서 확인했습니다. 홈·로그인·가입 화면 200, 익명 주식 화면·API 접근 302, CSRF를 포함한 가입·로그인·주식 등록 302, 로그인 후 주식 폼·목록 200과 저장 데이터 표시를 확인했습니다. API 로그인 200, 발급한 JWT로 검색 200과 Gap 20을 확인하고 서버를 종료했습니다.

설치된 Gradle 배포와 읽기 전용 의존성 캐시를 오프라인으로 사용했고, 캐시 쓰기와 임시 파일은 별도 작업 경로로 분리했습니다. 기존 `test` 프로필이 로컬 활성 프로필을 대체하는 실패는 테스트 설정의 명시적 H2 설정 가져오기로 수정했습니다. 운영 PostgreSQL·부하·동시성은 이번 검증 범위가 아닙니다.

## 해석 범위

- 기존 테스트 통과를 모든 인증 경계·동시성·운영 환경 검증으로 해석하지 않습니다.
- 일부 검색 컨트롤러 테스트는 직접 구성한 MockMvc를 사용하므로, 테스트 통과만으로 보안 필터 적용을 증명하지 않습니다.
- 실제 원격 PostgreSQL에는 접속하지 않았습니다.
- AI 모델의 예측 성능이나 투자 성과는 이 저장소 검증 대상이 아닙니다.
